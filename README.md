# JP Glass — Business Website

**A modern, responsive business website developed for a professional glass installation company based in Auckland, New Zealand.**

🌐 **Live Website:** https://jpglass.co.nz

## Overview

JP Glass is a real-world client project focused on designing and developing a professional digital presence for an Auckland-based glass installation business.

The website showcases the company's services, allows customers to explore customisation options, and provides a streamlined process for requesting quotes.

The project involved translating client requirements into a responsive, user-friendly website, from initial UI/UX design through to development, deployment and search engine optimisation.

## Tech Stack

| Category | Technologies |
|---|---|
| Framework | Next.js (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| UI Components | shadcn/ui, Radix UI |
| Icons | Lucide React |
| Forms | React Hook Form, Zod |
| Email Integration | Resend |
| Deployment | Vercel |
| Version Control | Git, GitHub |
| SEO | Google Search Console, Metadata |

## Key Features

### 1. Responsive Website Design
- Mobile-first layouts optimised for desktop, tablet and mobile devices.
- Reusable React components for consistent design and maintainability.
- Modern, minimal interface with intuitive navigation.
- Service-focused page layouts featuring high-quality project imagery.

### 2. Interactive Product Customisation
- Interactive option selectors for glass installations.
- Multiple frame finishes, glass types and installation configurations.
- Dynamic UI updates based on selected options.
- Image previews to help customers visualise available designs.

### 3. Service Showcase
Dedicated sections presenting the company's core services:

- Frameless, sliding and walk-in showers
- Glass balustrades
- Glass pool fencing
- Custom glass staircases
- Glass handrails

### 4. Customer Enquiry System
- Customer enquiry and quote request forms.
- Client-side form validation using React Hook Form and Zod.
- Email integration using Resend.
- User-friendly form interactions and validation feedback.

### 5. SEO & Deployment
- SEO-friendly page structure and metadata.
- Semantic HTML for accessibility and search visibility.
- Google Search Console integration.
- Custom domain configuration.
- Production deployment through Vercel.
